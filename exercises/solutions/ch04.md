# Chapter 4: Your First SELECT and How a Query Produces a Result — Explained Solutions

A Level A customer query is:

```sql
SELECT customer_id, customer_name, customer_type, city
FROM customers;
```

A supplier query is:

```sql
SELECT supplier_id, supplier_name, state
FROM suppliers;
```

The alias example is:

```sql
SELECT
    product_name AS item,
    unit_price AS current_price
FROM products;
```

The grain remains one row per branch because `SELECT` chooses attributes of each source row; it does not group or join them. For the API example, explicit columns communicate intent, transfer only needed data, and reduce coupling to future schema changes.
