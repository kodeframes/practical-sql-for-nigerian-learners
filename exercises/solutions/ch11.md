# Chapter 11: JOINs and Multi-Table Questions — Explained Solutions

Product categories:

```sql
SELECT p.product_name, c.category_name
FROM products AS p
JOIN categories AS c
    ON c.category_id = p.category_id
ORDER BY c.category_name, p.product_name;
```

Supplier-product relationships:

```sql
SELECT
    s.supplier_name,
    p.product_name,
    sp.supplier_unit_cost,
    sp.lead_time_days,
    sp.is_preferred
FROM supplier_products AS sp
JOIN suppliers AS s
    ON s.supplier_id = sp.supplier_id
JOIN products AS p
    ON p.product_id = sp.product_id
ORDER BY p.product_name, sp.is_preferred DESC, s.supplier_name;
```

One output row represents one supplier-product relationship.

For the professional challenge, calculate the order total at order grain first, then sum those totals at branch grain. Verify a few orders independently before trusting the branch total.
