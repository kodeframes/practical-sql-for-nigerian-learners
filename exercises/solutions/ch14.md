# Chapter 14: Common Table Expressions — Explained Solutions

Level B:

```sql
WITH order_totals AS (
    SELECT
        o.order_id,
        o.order_number,
        SUM(oi.quantity * oi.unit_price - oi.discount_amount)
            - o.discount_amount AS order_total
    FROM orders AS o
    JOIN order_items AS oi
        ON oi.order_id = o.order_id
    WHERE o.order_status = 'completed'
    GROUP BY o.order_id, o.order_number, o.discount_amount
)
SELECT order_number, order_total
FROM order_totals
WHERE order_total >= 100000
ORDER BY order_total DESC;
```

For Level C, one CTE can calculate orders, another branch totals, and a third or scalar subquery can calculate the average branch total. The important part is stating: order grain → branch grain → filtered branch grain.
