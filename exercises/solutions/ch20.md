# Chapter 20: Views, Indexes, EXPLAIN, and Query Performance — Explained Solutions

A plausible payment index is:

```sql
CREATE INDEX idx_payments_order_status_date
ON payments (order_id, payment_status, payment_date);
```

That order is reasonable for a workload that commonly constrains one `order_id` and a status before ordering or ranging by date. It is not universally optimal; actual query patterns and data decide.

The bulk load pays additional index-maintenance work for every inserted row. Performance design therefore balances reads, writes, storage, maintenance, and operational requirements.
