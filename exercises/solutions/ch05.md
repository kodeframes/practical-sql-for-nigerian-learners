# Chapter 5: Filtering Rows with WHERE — Explained Solutions

Level A examples:

```sql
SELECT product_id, product_name, unit_price
FROM products
WHERE is_active = true
  AND unit_price < 5000;
```

```sql
SELECT order_number, order_status
FROM orders
WHERE order_status IN ('pending', 'cancelled');
```

```sql
SELECT customer_id, customer_name
FROM customers
WHERE phone IS NULL;
```

For Level B:

```sql
SELECT customer_id, customer_name, state
FROM customers
WHERE customer_type = 'individual'
  AND is_active = true
  AND state IN ('Lagos', 'Oyo');
```

For Level C, you can define recent as a date range and perhaps “large” provisionally as a non-zero order-level discount or a business channel, but you **cannot** calculate true order value from `orders` alone because MarketLedger deliberately stores line quantities and transaction-time prices in `order_items`. That is the correct point to stop rather than inventing an `orders.total_amount` column.
