# Chapter 15: Window Functions for Real Analysis — Explained Solutions

A safe percentage expression can use `NULLIF`:

```sql
100.0 * (month_value - previous_month_value)
    / NULLIF(previous_month_value, 0)
```

The first month has no previous month, so the percentage is `NULL`. If a previous month total is zero, `NULLIF` avoids division by zero and signals that an ordinary percentage change is undefined.
