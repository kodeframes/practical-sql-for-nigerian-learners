# Chapter 2: Setting Up SQL on a Modest Computer — Explained Solutions

A good Level B checklist includes the actual server version, current database, table list, known row counts, and one relationship test such as checking that every `order_items.order_id` references an existing order. The important property is reproducibility: another person should be able to follow the checks and reach the same conclusion.

For Level C, essential items include the PostgreSQL installer, book, repository files, schema, seed, exercise scripts, and an editor. Optional items include a second GUI client or large documentation mirrors if local storage is tight.
