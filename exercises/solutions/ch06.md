# Chapter 6: Sorting, DISTINCT, LIMIT, and Result Control — Explained Solutions

A product sort:

```sql
SELECT product_id, product_name, unit_price
FROM products
WHERE is_active = true
ORDER BY unit_price ASC, product_id ASC;
```

Recent branches:

```sql
SELECT branch_id, branch_name, opened_date
FROM branches
WHERE is_active = true
ORDER BY opened_date DESC, branch_id DESC
LIMIT 3;
```

Distinct states:

```sql
SELECT DISTINCT state
FROM customers
WHERE state IS NOT NULL
ORDER BY state;
```

For orders, use `order_date DESC, order_id DESC` so same-day orders have a stable order. Deep `OFFSET` may make the engine walk past many rows, and changing data can shift page boundaries. Keyset pagination uses the last seen sort key as the next-page boundary instead of repeatedly counting from the beginning.
