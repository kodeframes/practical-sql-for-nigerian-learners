# Chapter 21: SQL in Applications, Reporting, and Secure Data Access — Explained Solutions

State and customer type are values and should be parameterised. The application should control the SQL identifiers.

The migration role can own or alter schema under controlled deployment; the runtime role gets only required operational reads/writes; the reporting role gets read access to approved tables or views. Exact grants depend on the application.

A BI tool may contain bugs, misconfiguration, compromised credentials, or unexpected features. A read-only role limits the damage regardless of what the tool intends to do.
