# Chapter 13: UNION, INTERSECT, and EXCEPT — Explained Solutions

The central design step is not the operator; it is matching result shape. For the archive problem, select the same conceptual columns in the same order, alias them consistently, and cast where types differ but represent the same domain.

For example:

```sql
SELECT customer_name AS name, city, state
FROM customers
WHERE is_active = true

UNION ALL

SELECT archived_name AS name, archived_city AS city, archived_state AS state
FROM archived_customers;
```

The second table is hypothetical and used only to illustrate shape alignment.
