# Chapter 7: Expressions, CASE, and NULL Handling — Explained Solutions

Net line value:

```sql
SELECT
    order_item_id,
    quantity * unit_price AS gross_line_value,
    quantity * unit_price - discount_amount AS net_line_value
FROM order_items;
```

Customer status:

```sql
SELECT
    customer_name,
    CASE WHEN is_active THEN 'active' ELSE 'inactive' END AS account_status
FROM customers;
```

Phone fallback:

```sql
SELECT customer_name, COALESCE(phone, '[no phone recorded]') AS phone_display
FROM customers;
```

For the Level B condition:

```sql
WHERE phone <> '08000000001'
   OR phone IS NULL
```

The Level C request invents a delivery completion value. Keep `delivered_at` as `NULL` and use `CASE` or `COALESCE` only to create an explicit display label such as `Not delivered`.
