# Chapter 9: Aggregation, GROUP BY, and HAVING — Explained Solutions

Customer types:

```sql
SELECT customer_type, COUNT(*) AS customer_count
FROM customers
GROUP BY customer_type
ORDER BY customer_type;
```

Products by category ID:

```sql
SELECT category_id, COUNT(*) AS product_count
FROM products
GROUP BY category_id
ORDER BY category_id;
```

Channels with at least two orders:

```sql
SELECT sales_channel, COUNT(*) AS order_count
FROM orders
GROUP BY sales_channel
HAVING COUNT(*) >= 2
ORDER BY order_count DESC, sales_channel;
```

One output row represents one sales channel.

For Level C, one precise query could total successful payments only; another could group amounts by `payment_status` so the report distinguishes successful, failed, and pending attempts.
