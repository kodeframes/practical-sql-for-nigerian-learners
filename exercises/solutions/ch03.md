# Chapter 3: How Relational Databases Organize Information — Explained Solutions

A `customers` row is one customer account; a `products` row is one sellable product; a `payments` row is one payment attempt or payment record for an order; a `deliveries` row is one delivery record for an order.

`order_items.unit_price` preserves the price that applied to the transaction. `products.unit_price` can change later without changing history.

The supplier columns create a fixed maximum and repeated structure. MarketLedger instead uses `supplier_products`, where each row links one supplier to one product. That structure supports any number of supplier-product relationships and can store relationship-specific facts such as supplier cost and lead time.
