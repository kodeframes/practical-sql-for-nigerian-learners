# Chapter 16: Data Types, CREATE TABLE, and Constraints — Explained Solutions

A category table:

```sql
CREATE TABLE category_practice (
    category_id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    category_name text NOT NULL UNIQUE,
    is_active boolean NOT NULL DEFAULT true
);
```

A stock-adjustment table could use numeric identifiers referencing `branches` and `products`, `quantity_change integer NOT NULL CHECK (quantity_change <> 0)`, `movement_date timestamptz NOT NULL`, and nullable `notes text`.

Text from an input form should be validated and converted into the domain type before or during a parameterised database command. Storing numeric money as arbitrary text shifts validation into every future query and allows inconsistent formats.
