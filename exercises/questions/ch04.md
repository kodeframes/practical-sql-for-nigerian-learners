## Hands-on Lab: build and verify a small projection

Start with a narrow query rather than `SELECT *`:

```sql
SELECT
    branch_code,
    branch_name,
    city,
    state
FROM branches;
```

Before running it, predict two things: how many columns the result should have, and what one result row represents. After running it, compare the actual row count with:

```sql
SELECT COUNT(*) AS branch_count
FROM branches;
```

Now change the column order without changing the row source:

```sql
SELECT
    city,
    branch_name,
    branch_code
FROM branches;
```

The result contains the same branch rows but presents a different projection. This distinction becomes increasingly important when later clauses alter row membership or row grain.
