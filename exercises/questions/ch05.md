## Hands-on Lab: prove that Boolean grouping changes meaning

Consider two requests:

1. completed web orders or completed phone orders;
2. completed web orders, plus every phone order regardless of status.

They sound similar, but they are not the same predicate. Write both explicitly.

The first can be expressed as:

```sql
SELECT order_number, sales_channel, order_status
FROM orders
WHERE order_status = 'completed'
  AND sales_channel IN ('web', 'phone');
```

A deliberately different second interpretation is:

```sql
SELECT order_number, sales_channel, order_status
FROM orders
WHERE (order_status = 'completed' AND sales_channel = 'web')
   OR sales_channel = 'phone';
```

Run both and compare the row sets. Do not judge correctness by which query returns more rows; correctness depends on which English requirement was intended.

### Lab verification

Rewrite each predicate using parentheses even where precedence would make them optional. Then inspect every returned row and explain, in words, why it qualifies. If you cannot explain one row without looking back at the SQL, the condition is not yet clear enough.
