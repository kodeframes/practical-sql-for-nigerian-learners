### Level A — Apply

1. Connect to PostgreSQL with `psql`.
2. Run `SELECT version();`.
3. Connect to `marketledger` and list its tables.

### Level B — Reason

### Level C — Professional Challenge

Design an offline-preparation checklist for a learner who expects to have no internet access for one week. Separate essential files from optional conveniences.

## Hands-on Lab: build an offline-ready PostgreSQL practice folder

Create a local folder for this book before you rely on an internet connection. A useful working structure is:

```text
practical-sql/
  setup-notes/
  schema/
  seed/
  chapter-sql/
  exports/
  troubleshooting/
```

Place copies of the canonical schema and seed scripts in the appropriate folders. In `setup-notes/README.txt`, record the PostgreSQL major version you installed, how you open `psql`, the local database name, and any non-default port you selected. Do **not** record the database password.

Connect with `psql` and run:

```sql
SELECT current_database(), current_user;
```

Then list relations with:

```text
\dt
```

If the canonical scripts have not yet been loaded, the result should be empty or limited to whatever objects you created yourself. After loading them, run `\dt` again and compare the difference.

### Lab verification

Close the terminal, disconnect from the internet if practical, reopen `psql`, and reconnect to the local database. The learning environment should still work because the PostgreSQL server, schema, seed data, manuscript, and exercises are local resources. If your setup depends on a browser-only SQL playground, it is not yet an offline-ready workflow.
