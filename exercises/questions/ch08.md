## Hands-on Lab: separate calendar questions from elapsed-time questions

Use `orders.order_date` for calendar grouping and `payments.payment_date` for timestamp-aware payment events. These columns answer different kinds of time questions.

Start with a reproducible extraction:

```sql
SELECT
    order_number,
    order_date,
    EXTRACT(YEAR FROM order_date) AS order_year,
    EXTRACT(MONTH FROM order_date) AS order_month
FROM orders
ORDER BY order_date, order_id;
```

Then inspect delivery timing:

```sql
SELECT
    delivery_id,
    dispatch_date,
    delivered_at,
    delivered_at - dispatch_date::timestamp AS elapsed_from_midnight
FROM deliveries
WHERE delivered_at IS NOT NULL
  AND dispatch_date IS NOT NULL;
```

The second expression is mathematically valid, but its meaning is constrained by the schema: `dispatch_date` contains no actual dispatch time, so midnight is an assumption introduced by the cast.
