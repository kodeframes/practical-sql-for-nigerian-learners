# Chapter 22: Capstone: MarketLedger Business Analysis — Practice Tasks

### Level A — Apply

Choose any three capstone queries and modify the date range or branch filter. Predict which rows will change before running them.

### Level B — Reason

Define “active customer” in two different defensible ways and write a query for each definition. Explain how the result sets differ.

### Level C — Professional Challenge

Prepare a one-page management note titled **What MarketLedger Can and Cannot Tell Us**. Include three supported metrics, two metrics that need explicit definitions, and two metrics the current schema cannot support.

## Hands-on Lab: produce a capstone evidence packet

Select three capstone questions with different grains: one branch-level metric, one customer-level absence question, and one product-level ranking question. For each, create a short evidence packet containing:

```text
Question
Definition
Tables
Join path
Output grain
SQL file
Expected result summary
Independent verification
Limitations
```

For branch value, derive order totals from transaction-time line values and subtract the order-level discount once. For customers with no purchases, use `NOT EXISTS` or a carefully verified `LEFT JOIN`. For product ranking, state whether you rank by units, line net value, current list price, or another explicit metric.

### Lab verification

Cross-check the branch totals against an overall total from the same order-total CTE. Manually inspect one customer classified as having no orders. For ranking, sort the underlying metric without the window function and confirm the rank order agrees.

The packet should be understandable to a reviewer who has not read the chapter. That is the standard for professional analytical evidence.
