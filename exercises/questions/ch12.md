## Hands-on Lab: express absence with NOT EXISTS

Find active customers who have never been attached to an order:

```sql
SELECT
    c.customer_id,
    c.customer_name
FROM customers AS c
WHERE c.is_active = TRUE
  AND NOT EXISTS (
      SELECT 1
      FROM orders AS o
      WHERE o.customer_id = c.customer_id
  )
ORDER BY c.customer_id;
```

Read the correlated condition carefully: for each candidate customer, the subquery asks whether any matching order exists. `NOT EXISTS` keeps only customers for whom the answer is no.

Now solve the same question with a `LEFT JOIN` and `IS NULL`. Compare results and explain why both are valid when the join condition is correct.

### Lab verification
